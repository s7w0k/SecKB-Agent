# Agent 行为审计与观测 — 商务与交付方案

## 报价模型
- 按事件量（条/月）订阅：标准版（≤5000 万条/月）、进阶版（≤2 亿条）、旗舰版（定制容量）
- 支持按年订阅，含留存时长与节点数；超出用量按梯度计费
- 提供数据留存时长增值包与专属分析师服务

## 交付流程
- 阶段一：审计范围与合规需求调研（1 周），明确采集对象
- 阶段二：POC 验证（1-2 周），完成 Agent 事件接入与还原演示
- 阶段三：正式部署与全量接入（2-4 周），配置基线与分析规则
- 阶段四：试运行与验收（2 周），输出审计报表与验收文档

## SLA 承诺
- 服务可用性 ≥ 99.9%，事件丢失率 ≤ 0.01%，采集链路 7×24 监控
- 故障响应 15 分钟内，重大故障 2 小时内恢复
- 提供季度数据完整性校验与年度合规审计支撑报告

## 合同与合规要点
- 满足等保 2.0 三级审计留存要求，支持数据本地化存储
- 明确审计数据所有权、留存期限与访问权限条款
- 支持 GDPR / 个保法对个人信息脱敏与最小化采集的要求
