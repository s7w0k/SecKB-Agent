# Agent 行为审计与观测 — 常见问题 FAQ

- 问：审计数据能留存多久？能否长期存档？
  答：默认 180 天，可配置扩展至 1 年；长期数据可归档至对象存储或大数据平台，按监管要求设置留存期限。

- 问：采集是否影响 Agent 运行性能？
  答：采用异步埋点与本地缓冲上报，对 Agent 执行延迟影响可忽略（<2%），支持配置采样率。

- 问：如何保证审计数据不被篡改？
  答：支持数据完整性校验与哈希链式校验，关键事件写入后不可变，满足司法取证要求。

- 问：能否还原一次事故的完整过程？
  答：可以，通过会话 ID 或 Trace ID 一键还原从提示词、工具调用到结果输出的完整时间线与调用链。

- 问：隐私数据如何处理？
  答：支持字段级脱敏与掩码、最小化采集原则，满足个保法与 GDPR 要求。

- 问：支持哪些 Agent 框架的接入？
  答：支持 LangChain、AutoGen、CrewAI 等框架的 Callback/Tracing，也支持通用 SDK 采集。

- 问：事件量很大如何承接？
  答：采用 Kafka + 分布式存储横向扩容，吞吐达 20 万条/秒以上，并提供采样与降级策略。

- 问：能否与现有 SIEM 对接？
  答：支持通过 Kafka、Webhook 推送事件至 ELK、SIEM 等平台，统一安全运营。

- 问：是否支持本地化与信创部署？
  答：支持私有化与鲲鹏、飞腾等信创架构，数据可完全本地化存储。

- 问：告警误报多怎么办？
  答：通过行为基线自学习与白名单规则持续调优，可将误报率降至 5% 以下。
