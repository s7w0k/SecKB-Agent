# Agent 行为审计与观测 — 使用指南

## 核心功能操作
- 会话检索：按时间、Agent、用户、会话 ID 检索完整会话时间线
- 操作审计：查看工具调用、参数、结果与状态码，支持一键还原执行过程
- 全链路追踪：查看单任务 Trace 的调用链、耗时与故障点
- 行为基线：查看基线规则、命中记录与异常评分

## 配置项说明
- 采集范围：选择采集的 Agent、事件类型与采样率
- 留存策略：按数据分级设置留存时长（默认 180 天）
- 脱敏规则：对敏感字段（密钥、个人数据）配置脱敏与掩码
- 告警规则：基于基线偏差、高频调用、越权操作等配置触发条件

## 告警与报表
- 告警级别：低/中/高/严重，支持邮件、Webhook、SIEM 推送
- 报表：合规审计报表、异常行为报表、工具调用 Top 榜、Agent 性能报表
- 支持定时生成与导出（CSV/PDF），满足监管报送

## 日常使用建议
- 建议按业务域划分审计看板，分角色授权查看范围
- 定期复核告警误判并调整基线，保持基线贴合实际行为
- 将审计数据与威胁情报联动，提升异常发现能力
