# Agent 行为审计与观测 — 维保升级与版本发布

## 升级流程
- 升级前：备份配置、索引与留存策略，确认版本兼容矩阵，申请变更窗口
- 升级中：在低峰期执行，先升级存储层索引 schema，再升级采集与展示服务
- 升级后：执行数据完整性校验与查询回归，核对告警规则与报表可用性
- 建议升级频率：季度安全补丁、年度大版本演进

## 补丁管理
- 安全与稳定性补丁随版本发布，高危缺陷 24 小时内出补丁
- 补丁发布前完成内部回归，提供一键回滚与升级说明

## 版本历史
- v1.0：首个商用版本，支持会话检索与操作审计
- v1.3：引入全链路 Trace 与行为基线引擎
- v1.6：新增脱敏与数据完整性校验，支持公私混合存储
- v2.0：提升吞吐至 20 万条/秒，支持大规模分布式集群

## 兼容性
- SDK 向后兼容一个主版本；采集协议兼容 OpenTelemetry
- 升级前确认与隔离沙箱、IAM 及 Agent 框架的版本匹配

## 退役/下线策略
- 退役前提供索引导出与数据迁移工具，确保审计留存期数据完整
- 下线流程包括：确认替代方案、导出审计数据、执行下线评审
- 提供 6 个月过渡期支持，期满后转为只读存档以延续合规留存
