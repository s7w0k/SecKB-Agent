# Agent 行为审计与观测 — 规格参数与系统架构

## 核心性能指标
- 审计事件采集吞吐 ≥ 20 万条/秒，单节点可横向扩容
- 事件写入延迟 ≤ 500ms，查询 P99 延迟 ≤ 1s（含索引）
- 单 Agent 会话时间线还原 ≤ 1s；全链路 trace 采样率可配（默认 100%）
- 数据留存默认 180 天，可按需扩展至 1 年或更久

## 部署形态
- 私有化：支持 x86_64 / ARM64 / 信创架构，单机或分布式集群
- 容器化：兼容 Kubernetes，提供 Helm 一键部署
- 数据存储：支持本地存储或对接对象存储/大数据平台

## 组件架构
- 采集层：Agent SDK、Sidecar 采集器、事件网关（支持 Kafka）多源接入
- 存储层：时序与全文索引存储（事件、会话、Trace）
- 分析层：行为基线引擎、关联分析引擎、报表服务
- 展示层：审计控制台、API、告警推送

## 依赖与规格
- 依赖 Kafka、对象存储；生产推荐至少 3 节点 16 核 64GB 集群
- 支持 OpenTelemetry 协议对接，兼容常见 APM 与日志平台
- 对外接口：RESTful API + Python / Go SDK，支持告警 Webhook
