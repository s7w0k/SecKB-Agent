# 模型安全红队评估平台 — 使用指南

## 功能操作
- 创建评测任务：选择目标模型、评测模板集、并发与判定策略，一键启动
- 模板管理：浏览、搜索、启用/禁用攻击模板，支持自定义模板并版本化
- 模型接入：在控制台配置在线 API 或本地权重模型，测试连通性
- 结果分析：按威胁类别、严重级别、模型回复逐条查看攻击详情与载荷

## 配置项
- 判定策略：单模型判定 / 多模型投票 / 人工复核阈值
- 并发控制：设置每节点并发数与请求超时，避免压垮目标模型
- 安全边界：配置目标模型内容过滤开关、禁用危险实验标记
- 告警阈值：设置风险分阈值，触发后自动生成告警并通知

## 告警与报表
- 评测完成时自动生成摘要告警，高风险模板命中可实时推送
- 报告含风险总评分、TOPN 高危漏洞、逐条证据链、整改建议
- 支持历史评测对比，生成安全回归趋势图
- 支持按部门/项目导出审计报表，满足内控要求

## 日常使用
- 建议每月对生产模型执行一次全量回归评测，新版模型发布前必测
- 将关键模型纳入自动评测计划，绑定 CI 门禁，失败阻断发布
- 定期更新攻击模板库，关注威胁情报订阅中的新增攻击手法
- 保留评测报告归档，作为合规审计与安全治理的佐证材料
