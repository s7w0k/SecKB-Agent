# Agent 隔离沙箱 — 故障排查

## 现象一：执行性能下降
- 排查步骤：检查宿主 CPU/内存是否超负载；核对沙箱资源配额是否过小、GC 是否频繁
- 检查是否命中大量策略审计导致事件堆积；查看事件队列消费是否滞后
- 定位点为"配置优先"：优先扩容节点或调大配额，再评估策略复杂度

## 现象二：误报/漏报
- 误报：检查配置项"告警阈值"与危险命令库版本，更新规则库或调整白名单
- 漏报：确认策略未生效、规则未加载；检查内核版本是否满足逃逸检测要求
- 定位点为"规则优先"：核对规则库版本与策略生效状态

## 现象三：沙箱启动失败/逃逸检测异常
- 排查步骤：检查内核版本与 cgroup/overlayfs 是否开启；查看沙箱运行时日志
- 检查 Docker/容器运行时版本兼容性；核对资源配额是否超节点上限
- 定位点为"环境优先"：先验证基础运行时，再升级补丁

## 现象四：集成失败（SDK/API）
- 排查步骤：核对 SDK 版本与产品版本兼容矩阵；检查 API 鉴权 Token 与端口连通性
- 检查请求参数是否符合 OpenAPI 规范；查看服务端错误码与日志
- 定位点为"接口优先"：抓取请求/响应报文比对文档

## 通用建议
- 收集日志目录 `/var/log/sandbox/`，保留现场后联系售后
- 提供产品版本号、内核版本、复现步骤与事件 ID 便于快速定位
