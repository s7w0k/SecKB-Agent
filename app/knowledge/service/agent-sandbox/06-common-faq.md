# Agent 隔离沙箱 — 常见问题 FAQ

- 问：与直接使用 Docker 容器隔离有何区别？
  答：容器共享宿主内核，逃逸风险高；本产品基于 gVisor 轻量虚拟机 + seccomp 双层隔离，默认拒绝主机资源访问，逃逸防护覆盖 90% 以上已知向量，且提供统一策略与审计能力。

- 问：接入是否必须改造现有 Agent 代码？
  答：不需要。提供 SDK 接入与 Sidecar 透明代理两种方式，Sidecar 方式无需改动业务代码即可接入。

- 问：支持的隔离方式有哪些？能否资源限制？
  答：支持轻量虚拟机 + 命名空间 + seccomp 组合，可限制 CPU、内存、磁盘、网络与执行超时。

- 问：沙箱内允许访问外部网络吗？
  答：默认拒绝出网，需通过网络白名单按域名/IP/端口放行，最小化网络暴露面。

- 问：是否影响 Agent 执行性能？
  答：平均执行延迟增量约 8%，P99 ≤ 200ms，对绝大多数业务影响可忽略。

- 问：是否支持信创与国产化环境？
  答：支持鲲鹏、飞腾、海光等 ARM64/x86_64 信创架构，可本地化私有化部署。

- 问：发生逃逸尝试时产品如何处置？
  答：触发策略引擎实时阻断并隔离，产生严重级告警，同时记录完整事件供审计追溯。

- 问：支持哪些 Agent 框架？
  答：支持 LangChain、AutoGen、CrewAI、LlamaIndex 等主流框架，并提供对应集成示例。

- 问：审计事件可否对接第三方平台？
  答：可，支持通过 Kafka、Webhook 推送至 ELK、SIEM 等平台。

- 问：最小投入即可使用吗？
  答：是的，单节点 8 核 32GB 即可部署基础版，POC 阶段免费验证。
