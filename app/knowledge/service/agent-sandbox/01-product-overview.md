# Agent 隔离沙箱 — 产品概述与定位

## 解决的核心问题
- 企业 Agent（执行代码、调用命令、访问文件系统）在内网或生产环境运行，一旦提示词注入、恶意工具调用或模型幻觉导致越权执行，将造成数据泄露与系统破坏
- 解决"Agent 代码/命令执行不可控、逃逸风险高、无事件留痕"三类核心痛点

## 目标客户
- 依赖 LangChain / AutoGen / CrewAI / LlamaIndex 构建智能体的金融、政务、制造、运营商等行业客户
- 对代码执行安全和运行隔离有合规诉求的安全团队与平台工程团队

## 核心价值
- 提供基于 gVisor + seccomp + 命名空间的轻量级轻虚拟机隔离，默认拒绝一切主机资源访问
- 运行时策略引擎（网络白名单、文件沙盒、系统调用拦截）默认安全，逃逸防护覆盖 90% 以上已知逃逸向量
- 全量事件留痕，可与审计观测产品联动，形成执行闭环

## 适用场景
- CI/CD 流水线中 Agent 自动生成并执行代码
- 数据分析 Agent 执行 SQL / Python / Shell
- 自动化运维 Agent 调用系统命令与接口

## 竞品差异
- 相比开源 gVisor/Firecracker 单点方案，提供统一策略面、审计面与告警面
- 相比云厂商容器沙箱，支持本地化私有化部署与信创环境适配
- 主打"零改造接入"：无需改写 Agent 代码，通过 SDK 与 Sidecar 两种方式接入
