# Agent 隔离沙箱 — 使用指南

## 核心功能操作
- 沙箱模板管理：创建/编辑执行环境模板，预设依赖与资源额度
- 策略配置：配置网络白名单、文件访问白名单、系统调用黑名单
- 执行请求：提交代码/命令执行任务，查看实时执行状态与输出
- 事件查看：检索沙箱事件、查看逃逸阻断告警与处置建议

## 配置项说明
- 资源配额：CPU 核数、内存、临时磁盘、执行超时（默认 60s）
- 网络策略：默认拒绝出网，按需放行域名/IP 与端口
- 文件策略：默认只读挂载，可配置读写目录白名单
- 危险命令库：内置 rm -rf、dd、shutdown 等高风险命令识别

## 告警与报表
- 告警级别：低/中/高/严重，支持邮件、Webhook、SIEM 推送
- 违规执行、逃逸尝试、资源异常均触发告警，支持去重与聚合
- 提供执行趋势、逃逸阻断统计、Top 风险 Agent 等报表，支持导出

## 日常使用建议
- 建议按 Agent 类型划分不同沙箱模板，最小化权限
- 定期（建议每周）复核策略变更与告警处理记录
- 将沙箱事件接入审计观测平台，形成执行全链路留痕
