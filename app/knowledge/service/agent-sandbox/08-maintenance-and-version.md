# Agent 隔离沙箱 — 维保升级与版本发布

## 升级流程
- 升级前：备份配置与策略、确认版本兼容矩阵、申请变更窗口
- 升级中：在低峰期执行，先升级控制面，再滚动升级数据面沙箱运行时
- 升级后：执行健康检查与回归用例，核对策略与事件数据完整性
- 建议升级频率：季度安全补丁、年度大版本演进

## 补丁管理
- 安全补丁（逃逸漏洞、CVE）随版本发布，重大漏洞 24 小时内出补丁
- 补丁发布前完成内部验证，提供回滚机制与升级说明文档

## 版本历史
- v1.0：首个商用版本，支持 gVisor 隔离与基础策略引擎
- v1.2：新增信创架构支持与 Sidecar 透明代理接入
- v1.5：强化逃逸检测规则库，新增网络白名单精细化管控
- v2.0：引入事件总线与审计联动，支持大规模横向扩容

## 兼容性
- 兼容 Docker 20.10+、Kubernetes 1.24+；SDK 向后兼容一个主版本
- 升级前需确认与 Agent 框架（LangChain 等）及 IAM/审计产品的版本匹配

## 退役/下线策略
- 退役前提供数据迁移与策略导出工具，保留审计留存期内的数据
- 下线流程包括：确认替代方案、导出配置与事件、执行下线评审
- 提供 6 个月过渡期支持，期满后转为只读存档
