# 模型指纹与来源追踪 — 部署安装与集成

## 环境要求
- 系统：CentOS 7.9+、Ubuntu 20.04+、麒麟 V10、统信 UOS
- 指纹提取节点需 GPU（NVIDIA 驱动 470+ / CUDA 11.8+ 或国产 GPU 驱动）
- 比对节点最小 8 vCPU / 16GB / 200GB；容器化需 Kubernetes 1.24+
- 网络：各节点与数据库、向量库互通，开放管理端口

## 安装步骤
- 部署控制面、数据库与向量检索引擎，创建管理员账号
- 部署指纹提取节点并配置 GPU 环境，验证模型推理联通
- 配置指纹加密密钥（KMS），导入存量模型资产并生成指纹

## API/SDK 集成
- 提供管理 API（OpenAPI）用于模型登记、指纹生成、比对查询与溯源
- 提供 Python SDK 便于与模型训练/发布流水线集成
- 支持 Webhook 通知比对命中与溯源事件

## 与客户系统对接
- 对接模型训练与发布平台（如 MLflow、Kubeflow），自动登记新模型
- 对接模型仓库（HuggingFace Hub、私有仓库）定时比对发现盗版
- 对接 SIEM/审计平台归档比对与取证事件
- 支持接入 CI/CD 在模型发布前自动生成指纹并入库
