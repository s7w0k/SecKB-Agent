# 模型指纹与来源追踪 — 故障排查

## 现象：指纹提取失败或超时
- 检查 GPU 驱动与 CUDA 版本是否满足要求，确认显存充足
- 核对模型权重格式与读取路径，确认模型可被正常加载
- 查看提取节点日志定位格式不支持或内存溢出，必要时调整批次

## 现象：比对结果异常（漏匹配/误报）
- 确认指纹参数与鲁棒性级别是否匹配目标篡改程度
- 核对相似度阈值与派生判定规则，用已知样本回归验证
- 检查指纹库是否包含最新基线，必要时重新提取指纹

## 现象：集成失败（仓库/流水线对接异常）
- 核对模型仓库地址与鉴权，使用连通性测试定位
- CI/CD 对接失败时检查 API 密钥与版本，参照集成文档校验参数
- 确认 Webhook 回调地址可达与签名配置正确

## 现象：服务异常（崩溃/检索慢）
- 查看控制面与比对节点日志，定位 OOM 与磁盘满
- 检查数据库与向量检索引擎连接，指纹库过大时评估扩展
- 高并发比对超时检查检索节点 CPU 与索引分片配置

## 通用排查步骤
- 收集平台日志、模型/比对样本与时间范围，联系技术支持
- 核对版本号，确认是否可升级到含修复的 patch，必要时回滚配置
