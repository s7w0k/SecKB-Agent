# 大模型安全网关 — 产品概述与定位

## 产品是什么
MindBridge 大模型安全网关（产品代号 AegisGate，当前版本 v4.1）是企业与外部大模型之间的统一安全代理层。它位于业务应用与模型 API 之间，对请求与响应进行实时检测、审计与管控，实现"入口防注入、出口防泄漏、全程可审计"的 LLM 防火墙能力，同时提供模型调用治理与成本管控。

## 解决什么问题
- LLM 应用绕过企业安全管控，敏感数据被当作 Prompt 发送给外部模型
- 提示注入、越狱攻击无防护，模型输出嵌入不当内容
- 多模型接入缺乏统一鉴权、限流、审计与故障切换机制

## 目标客户
- 已上线或计划上线 LLM 应用的中大型企业、金融机构、政务平台
- 需要统一管理多家模型供应商、控制 AI 成本与数据出境的企业
- 对生成内容合规与可审计性有强要求的行业

## 核心价值
- 双向内容检测：请求侧防数据外泄与注入，响应侧防有害内容与个人隐私
- 统一网关能力：路由、限流、熔断、灰度、多模型灾备切换
- 全链路审计：记录每次调用的身份、内容摘要、风险判定与合规标记

## 适用场景
- LLM 应用生产环境前置防护、企业私有化 AI 平台统一出口、跨境数据合规管控

## 竞品差异
- 相比通用 API 网关，内置专为大模型定制的语义检测引擎，攻击识别更准
- 支持请求/响应双向深度检测与敏感信息脱敏，通用网关无法覆盖
- 提供开箱即用的合规审计报告，满足监管与内控要求
