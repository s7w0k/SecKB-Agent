# 大模型安全网关 — 故障排查

## 现象：吞吐下降、延迟升高
- 检查检测引擎节点 CPU 是否饱和，必要时横向扩容
- 查看 Redis 限流是否误触发，确认限流阈值配置合理
- 排查上游模型响应变慢，确认是否为上游瓶颈而非网关问题

## 现象：误报/漏报（检测异常）
- 查看命中日志确认匹配的具体规则，误报时调整关键词或豁免范围
- 漏报时升级检测规则库，确认是否因采样率过低遗漏命中记录
- 检查脱敏与阻断策略是否与预期一致，核对策略版本

## 现象：集成失败（模型接入/透传异常）
- 核对上游模型 API Key 与鉴权配置，使用连通性测试定位
- 流式（SSE）场景确认协议兼容性，检查是否被检测引擎缓冲
- 检查网关与上游、与业务网络是否互通，核对防火墙端口

## 现象：服务异常（崩溃/重启）
- 查看网关进程/容器日志，定位 OOM 与磁盘满
- 检查数据库连接池与 Redis 连接，必要时扩容
- 双活部署时确认故障切换是否正常，检查主备心跳

## 通用排查步骤
- 收集网关日志、审计命中记录、调用时间范围，联系技术支持
- 核对版本号，确认是否可升级到含修复的 patch，必要时回滚配置快照
