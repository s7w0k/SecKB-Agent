# 大模型安全网关 — 规格参数与系统架构

## 性能指标
- 单节点吞吐 ≥ 5,000 QPS，P99 延迟增加 ≤ 15ms（不含模型推理时间）
- 内容检测引擎单请求处理 ≤ 8ms，可水平扩展至 ≥ 50,000 QPS
- 误报率 ≤ 1%，漏报率 ≤ 0.5%（针对提示注入与敏感信息类目）
- 网关自身可用性 ≥ 99.99%（双活部署）

## 部署形态
- 支持 Kubernetes 部署、裸金属集群、边车（Sidecar）模式与一体机交付
- 支持多环保留：主中心 + 灾备中心，故障自动切换

## 组件架构
- 流量代理层（Proxy）：http/https 转发、gRPC 支持、协议解析
- 检测引擎（Detection Engine）：语义注入检测、敏感信息识别、内容合规判定
- 治理引擎（Governance）：路由、限流、熔断、灰度、密钥管理与多模型灾备
- 审计服务（Audit）：全量调用日志、脱敏存储、合规报表
- 控制台（Console）：策略配置、实时监控、告警与报表

## 依赖与软硬件规格
- 单节点建议 8 vCPU / 16GB 内存 / 200GB 磁盘，集群按 QPS 规划
- 依赖 Redis 7+（限流/缓存）、PostgreSQL 15+ 或国产数据库（审计存储）
- 上游支持主流模型 API：OpenAI、Anthropic、DeepSeek、Qwen、Gemini、本地 vLLM/Ollama
- 支持国产化系统（麒麟/统信）与国产 CPU（海光/鲲鹏）适配
