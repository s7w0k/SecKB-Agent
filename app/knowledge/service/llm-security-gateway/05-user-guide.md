# 大模型安全网关 — 使用指南

## 功能操作
- 模型路由：为不同业务配置默认模型、灰度比例与故障切换顺序
- 策略配置：请求侧配置敏感数据识别与注入防护规则，响应侧重垂与有害内容过滤
- 权限管理：按部门/应用分配调用白名单、配额与豁免策略
- 故障演练：一键模拟上游模型故障，验证熔断与灾备切换

## 配置项
- 检测策略：敏感信息类型（手机号、身份证、银行卡、密钥）、注入关键词、合规类目
- 治理策略：QPS 限流、并发限制、Token 配额、超时与重试、熔断阈值
- 脱敏策略：命中敏感信息时遮罩、替换或阻断的细粒度动作
- 审计策略：采样率、日志保留周期（默认 180 天）、访问控制

## 告警与报表
- 实时监控面板：QPS、延迟、错误率、检测命中率、上游模型健康度
- 告警规则：检测命中、熔断触发、配额超限、上游异常自动告警
- 合规报表：按应用/模型/风险类目生成调用审计与合规报告
- 支持导出审计日志用于内控与监管核查

## 日常使用
- 每周检查告警与命中趋势，优化策略降低误报
- 模型版本或供应商变更时，先在灰度路由验证再全量切换
- 定期备份策略配置与审计数据，参与定期熔断演练
- 关注策略库与检测规则更新，及时升级以应对新型攻击手法
