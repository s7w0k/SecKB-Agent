# 多 Agent 协作安全 — 故障排查

## 现象一：消息校验延迟升高
- 排查步骤：检查消息校验节点负载与网络延迟；核对签名算法与密钥缓存
- 检查消息吞吐是否超规格；查看防污染引擎资源占用
- 定位点为"资源优先"：扩容校验节点或优化密钥缓存

## 现象二：误拦/漏拦（防污染失真）
- 误拦：检查注入模式库是否过严；核对白名单与阈值配置
- 漏拦：确认规则库版本过旧、检测未启用；核对高危规则生效状态
- 定位点为"规则优先"：更新规则库并复核策略配置

## 现象三：编排框架接入失败
- 排查步骤：核对 SDK 版本与编排框架版本兼容性；检查消息通道连通性
- 检查消息协议格式与签名证书是否匹配；查看接入日志与错误码
- 定位点为"接口优先"：抓取消息报文比对文档

## 现象四：服务异常/消息大规模阻断
- 排查步骤：检查可信服务进程与密钥轮换状态；核对 KMS 可用性
- 检查时钟同步是否漂移导致验签失败；查看证书有效期与告警
- 定位点为"状态优先"：核对服务状态、密钥与时钟

## 通用建议
- 收集服务日志目录 `/var/log/multiagent/`，保留现场后联系售后
- 提供产品版本号、消息 ID、错误码与复现步骤便于快速定位
