# 多 Agent 协作安全 — 维保升级与版本发布

## 升级流程
- 升级前：备份可信策略、防污染规则库与密钥配置，核对版本兼容矩阵
- 升级中：在低峰期执行，先升级可信层，再升级防污染与编排面防护组件
- 升级后：执行消息签名/验签与防污染回归，核对策略与密钥状态
- 建议升级频率：季度安全补丁、月度规则库更新、年度大版本演进

## 补丁管理
- 安全补丁（签名算法缺陷、注入绕过分流）随版本发布，高危缺陷 24 小时内出补丁
- 防污染规则库每周更新，重大威胁即时推送，支持一键更新

## 版本历史
- v1.0：首个商用版本，支持消息签名与完整性校验
- v1.2：新增防污染引擎与注入模式库，支持主流编排框架
- v1.5：引入编排面访问控制与任务路由校验
- v2.0：消息校验吞吐提升至 50 万条/秒，支持 A2A/MCP 协议

## 兼容性
- SDK 向后兼容一个主版本；消息协议优先向上兼容
- 升级前确认与编排框架、IAM、审计产品及密钥体系版本匹配

## 退役/下线策略
- 退役前提供策略与密钥导出、消息回放验证工具，确保协作链路可切换
- 下线流程包括：确认替代方案、导出防护策略、执行下线评审
- 提供 6 个月过渡期支持，期满后关闭防护服务并归档审计数据
