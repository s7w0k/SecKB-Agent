# 多 Agent 协作安全 — 产品概述与定位

## 解决的核心问题
- 多个 Agent 协作时消息在 Agent 间传递，存在消息伪造、篡改、污染与编排面被劫持的风险
- 解决"协作协议不可信、消息防污染难、编排面攻击面大"三类核心痛点

## 目标客户
- 使用多 Agent 系统（AutoGen、CrewAI、LangGraph）进行复杂业务协同的企业
- 对协作链路安全与消息完整性有高要求的金融、政务、电信行业

## 核心价值
- 提供协作协议可信机制，为 Agent 间消息提供签名、加密与完整性校验
- 内置消息防污染检测，识别并阻断提示词注入、消息篡改、脏数据注入
- 强化编排面安全，对编排器、任务分发与消息路由做访问控制与校验
- 全生命周期留痕，支持协作链路审计与溯源

## 适用场景
- 多 Agent 分工协作的复杂任务编排
- 跨系统/跨部门 Agent 数据交换的可信保障
- 面向外部 Agent 协作时的身份与消息可信治理

## 竞品差异
- 相比开源消息总线，原生支持 Agent 间消息语义级防污染与可信校验
- 相比单一安全产品，提供协作协议、消息防污染、编排面一体化的防护
- 与隔离沙箱、IAM、审计产品联动，形成多 Agent 安全体系
