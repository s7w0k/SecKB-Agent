# 多 Agent 协作安全 — 常见问题 FAQ

- 问：本产品解决什么问题？
  答：解决多 Agent 协作时消息伪造、篡改、污染与编排面被劫持的安全风险，提供可信基座与防护能力。

- 问：支持哪些多 Agent 编排框架？
  答：支持 AutoGen、CrewAI、LangGraph 等主流框架，支持消息协议扩展（A2A、MCP）。

- 问：消息如何保证可信？
  答：为 Agent 间消息提供签名、加密与完整性校验，伪造或篡改消息会被识别并阻断。

- 问：什么是消息防污染？
  答：对 Agent 间传递内容进行注入检测、篡改识别与脏数据过滤，阻断提示词注入等污染。

- 问：是否影响协作性能？
  答：签名/验签延迟 ≤1ms，防污染检测 ≤10ms，对协作链路性能影响可忽略。

- 问：编排面安全包含什么？
  答：对编排器、任务分发与消息路由做访问控制与校验，防止编排被劫持或越权调度。

- 问：接入需要改造现有系统吗？
  答：提供 SDK 与 Sidecar 两种方式，Sidecar 方式无需改动业务代码即可接入。

- 问：支持哪些消息协议？
  答：支持 HTTP/gRPC，并支持 A2A、MCP 等 Agent 消息协议标准扩展。

- 问：是否支持信创与本地化部署？
  答：支持私有化与鲲鹏、飞腾等信创架构，密钥可本地托管。

- 问：与其他安全产品如何联动？
  答：与隔离沙箱、IAM、审计产品联动，形成多 Agent 协作全链路安全体系。
