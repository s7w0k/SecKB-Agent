# 多 Agent 协作安全 — 规格参数与系统架构

## 核心性能指标
- 消息校验吞吐 ≥ 50 万条/秒，消息签名/验签延迟 ≤ 1ms
- 防污染检测率 ≥ 99% 的已知注入模式，检测延迟 ≤ 10ms
- 支持并发协作任务 ≥ 10000，编排面 QPS ≥ 5000
- 消息留存与审计吞吐 ≥ 20 万条/秒，支持横向扩容

## 部署形态
- 私有化：支持 x86_64 / ARM64 / 信创架构，单机或多节点集群
- 容器化：兼容 Kubernetes，提供 Helm 一键部署
- 支持 Sidecar 与代理网关两种接入方式，适配多种编排框架

## 组件架构
- 可信层：消息签名与加密、密钥管理、完整性校验
- 防护层：防污染引擎（注入检测、篡改识别、脏数据过滤）
- 编排面安全：编排器访问控制、任务路由校验、防劫持
- 关联组件：审计通道、告警模块、SDK 客户端

## 依赖与规格
- 依赖 KMS 管理密钥；生产建议至少 3 节点 8 核 32GB
- 支持 AutoGen、CrewAI、LangGraph 等主流多 Agent 编排框架
- 对外接口：RESTful API + Python / Go SDK，支持消息协议（如 A2A/MCP）扩展
