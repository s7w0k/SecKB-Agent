# 多 Agent 协作安全 — 使用指南

## 核心功能操作
- 可信策略：配置消息签名、加密与完整性校验规则
- 防污染检测：查看注入/篡改/脏数据命中记录与处置建议
- 编排面防护：配置编排器访问控制、任务路由校验规则
- 协作溯源：检索协作链路，还原消息流转与阻断过程

## 配置项说明
- 签名策略：签名算法（Ed25519/ECDSA）、密钥周期、校验失败处置（阻断/告警）
- 防污染规则：注入模式库、敏感词/脏数据过滤、阈值与白名单
- 编排面规则：编排器权限、任务路由白名单、异常编排告警
- 消息留存：协作消息保存时长与归档策略

## 告警与报表
- 告警：伪造消息、篡改、注入、编排劫持均触发告警，分级推送
- 报表：协作链路可信度、防污染命中统计、编排面风险报表
- 支持定时生成与导出，供安全评估与合规报送

## 日常使用建议
- 建议定期审查防污染规则库版本并更新（默认每周更新）
- 对高风险协作链路启用强校验与全量留存
- 将协作消息审计接入审计观测平台统一分析
