# 智能数据防泄漏 DLP-AI — 故障排查

## 现象：检测性能下降、吞吐降低
- 检查探针 CPU/内存与镜像口流量负载，必要时扩容探针节点
- 查看 ES 索引写入是否积压，评估事件量并扩容存储
- 确认语义引擎是否启用 GPU 加速，纯 CPU 场景可评估升级

## 现象：误报/漏报（识别异常）
- 查看命中详情确认具体规则，误报时调整规则或加入白名单
- 漏报时核对规则库与语义模型版本，确认是否因通道未覆盖
- 检查 LLM 通道适配器是否正常接入，确认上下文获取完整

## 现象：集成失败（Agent/探针/网关对接异常）
- 端点 Agent 上报失败时检查网络与 Agent 版本，确认服务端端口可达
- 探针未检测到流量时确认镜像口配置与 SPAN/TAP 状态
- 网关对接失败时核对 API 密钥与协议，参考集成文档校验参数

## 现象：服务异常（崩溃/磁盘满）
- 查看控制台与探针日志，定位 OOM 与磁盘满（事件数据增长快）
- 检查数据库与 ES 连接，必要时扩容并重启相关服务
- 确认探针与控制器心跳正常，网络分区时检查主备配置

## 通用排查步骤
- 收集平台日志、事件 ID、时间范围，联系技术支持
- 核对版本号，确认是否可升级到含修复的 patch，必要时回滚策略
