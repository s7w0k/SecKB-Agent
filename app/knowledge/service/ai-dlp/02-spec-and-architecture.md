# 智能数据防泄漏 DLP-AI — 规格参数与系统架构

## 性能指标
- 网络数据流检测吞吐 ≥ 10 Gbps 单节点，支持多节点水平扩展
- 内容识别单文档 ≤ 100ms，语义引擎单请求 ≤ 200ms
- 敏感识别准确率 ≥ 98%，误报率 ≤ 1.5%
- 事件处理能力 ≥ 10,000 事件/秒，告警延迟 ≤ 5 秒

## 部署形态
- 支持旁路镜像（TAP/SPAN）网络检测、端点 Agent 部署、API/云缓存检测
- 支持私有化集群、Kubernetes 部署与一体机交付

## 组件架构
- 采集层（Collector）：网络探针、端点 Agent、LLM 通道适配器
- 识别引擎（Engine）：规则识别（正则/指纹）+ AI 语义识别 + 结构化数据发现
- 策略引擎（Policy）：策略编排、处置动作（阻断/告警/隔离）、白名单
- 事件与审计（Event）：事件存储、溯源取证、水印追踪
- 控制台（Console）：策略配置、事件调查、报表与合规

## 依赖与软硬件规格
- 控制面建议 8 vCPU / 32GB / 500GB；网络探针按吞吐配置 4–32 vCPU
- 依赖 PostgreSQL 15+ 或国产数据库、Redis 7+、Elasticsearch 8+（事件检索）
- 支持国产化系统（麒麟/统信）与国产 CPU/数据库适配
- 支持与模型网关、API 网关联动获取 LLM 调用上下文
