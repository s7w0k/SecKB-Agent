# 智能数据防泄漏 DLP-AI — 常见问题 FAQ

## 问：会不会影响正常业务与网络性能？
答：网络探针采用旁路镜像检测，不阻断链路；端点 Agent 资源占用低，处置动作可配置为仅记录。

## 问：误报怎么处理？
答：误报率 ≤ 1.5%，可通过白名单、规则调优与复核降低；命中事件默认仅告警可确认后再阻断。

## 问：能识别哪些敏感数据？
答：支持身份证号、银行卡、手机号、源代码指纹、密钥、合同文本等，以及 AI 语义级自定义识别。

## 问：如何覆盖 LLM 应用泄漏？
答：通过对接模型网关/API 网关，检测 Prompt 与模型响应中的敏感数据并处置。

## 问：数据会存储到厂商侧吗？
答：私有化部署数据全程留在客户域内，企业版可关闭遥测，详见 DPA 协议。

## 问：支持哪些操作系统？
答：端点 Agent 支持 Windows、Linux、macOS；控制系统支持麒麟/统信等国产化环境。

## 问：POC 怎么申请？
答：提供脱敏样本与镜像流量即可，14 天内完成敏感数据发现与处置验证。

## 问：能否满足等保与个保法要求？
答：提供处置、审计与溯源能力，可导出证据包满足等保 2.0 与 PIPL 合规举证。

## 问：部署需要 GPU 吗？
答：语义识别引擎可选 CPU 版或 GPU 加速版，纯规则识别无需 GPU。

## 问：与现有 DLP 冲突吗？
答：本产品可叠加部署，聚焦 AI 与语义场景，也可作为现有 DLP 的语义能力增强。
