# Agent 凭证保险库 — 使用指南

## 功能操作
- 凭证托管：录入/导入密钥、证书、云凭证、数据库口令，绑定用途与归属。
- 动态下发：为 Agent/任务签发限时最小权限凭证，配置有效期，到期自动回收。
- 自动轮换：按策略设置轮换周期，启动自动轮换并监控宽限期与回滚。
- 审计查询：查看凭证使用、签发、轮换全量记录。

## 配置项
- 最小权限策略、凭证有效期、轮换周期与宽限期、访问控制（RBAC/ABAC）、通知渠道。
- 通知：密钥即将过期、轮换失败、异常访问（邮件/Webhook）。

## 告警与报表
- 告警：密钥过期、轮换失败、可疑访问、权限超限、硬编码凭证扫描结果。
- 报表：凭证使用量、轮换成功率、权限收敛度、审计导出。
- 审计：全量留痕（谁、何时、哪个 Agent、用了哪个凭证），支持合规导出。

## 日常使用
- 建议开启自动轮换与过期告警；定期复核最小权限与异常访问；季度执行权限收敛与硬编码扫描。
