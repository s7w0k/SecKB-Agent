# Agent 凭证保险库 — 故障排查

## 下发失败/延迟高
- 检查数据库/Redis 连接与连接池、网络与鉴权；核对最小权限策略是否冲突。
- 检查是否被大批量轮换抢占资源。
- 处理：扩容节点、削峰、检查策略配置；抓日志按错误码排查。

## 轮换失败
- 检查目标系统是否支持相应凭证类型、旧凭证是否仍有效、宽限期是否过短。
- 检查轮换回调是否超时、目标系统凭据同步是否完成。
- 处理：核对目标系统兼容性、延长宽限期、手动触发回滚并重试。

## 集成失败（SDK/Agent 接入不通）
- 核对 SDK 版本与保管库版本兼容、鉴权与网络白名单；检查与网关的联动配置。
- 检查动态下发回调地址与证书是否有效。
- 处理：验证最小调用连通后重试，必要时开启调试日志。

## 服务异常（保管库不可用）
- 检查集群节点健康、数据库/Redis 状态、根密钥与证书有效性、磁盘空间。
- 处理：按高可用预案切换节点、排查资源泄漏；持续异常升级 P1 工单。
