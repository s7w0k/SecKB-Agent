# Agent 凭证保险库 — 常见问题 FAQ

- 问：支持托管哪些凭证？
- 答：支持 API Key、数据库口令、云 AccessKey、TLS 证书及自定义密钥等，统一建模管理。
- 问：动态下发与普通读取有何区别？
- 答：普通读取返回持久凭证；动态下发签发限时、最小权限的一次性凭证，用后即回收，降低泄露风险。
- 问：如何实现自动轮换？
- 答：按策略设置轮换周期，系统自动签发新凭证、进入宽限期、切换后回收旧凭证，失败可回滚。
- 问：会不会影响 Agent 性能？
- 答：凭证读取 P99 ≤ 10ms，动态下发并发 ≥ 5000 次，对 Agent 影响极小。
- 问：凭证泄露了怎么办？
- 答：可立即吊销/轮换对应凭证，审计查询可定位使用来源，配合应急响应快速止血。
- 问：是否支持私有化？
- 答：支持，可部署于客户机房高可用集群，可选对接 HSM 升级根保护。
- 问：与 Agent 安全网关如何联动？
- 答：网关为 Agent 调用申请最小权限凭证时保管库动态下发并限时，实现凭证与调用行为联动审计。
- 问：能发现硬编码密钥吗？
- 答：提供硬编码凭证扫描，可扫描代码与配置提示替换为动态下发。
- 问：审计日志保留多久？
- 答：默认 180 天，可配置延长或对接 SIEM 归档合规模时间要求。
- 问：从现有 KMS 迁移麻烦吗？
- 答：支持批量迁移与宽限期并行，迁移期间新旧凭证均可使用，避免中断。
