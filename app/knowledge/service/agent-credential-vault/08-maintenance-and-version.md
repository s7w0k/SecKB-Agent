# Agent 凭证保险库 — 维保升级与版本发布

## 升级流程
- 升级前备份数据库与根密钥材料、核对兼容性矩阵；务必在测试环境验证后灰度升级（凭证系统关键）。
- 节奏：每季度功能版本，每月安全补丁，按需紧急修复；支持滚动升级与一键回滚。
- 升级操作：先升级保管库核心，再升级 SDK/接入层，执行迁移脚本与下发/轮换回归测试。

## 版本历史
- v2.0（2025-05）：集中托管、动态下发、RBAC 审计。
- v2.1（2025-09）：自动轮换引擎、HSM 集成、硬编码扫描。
- v2.2（2026-01）：Agent 网关联动增强、多租户、审计 BI。
- 当前推荐 LTS：v2.2（LTS），维护支持至 2028-01。

## 兼容性与升级影响
- 升级前核对 SDK 与保险库版本兼容（需同大版本）；API 保持向后兼容。
- 升级不中断存量托管凭证与在途下发，完成后需复核轮换与访问策略。

## 退役与下线策略
- LTS 停更后提供 12 个月安全维护期，之后进入退役观察期。
- 下线前导出并迁移托管凭证与审计日志，完成密钥销毁与权限回收确认，提供迁移工具。
- EOL 前 90 天邮件通知，协助规划升级路径。
