# Agent 凭证保险库 — 产品概述与定位

## 产品代号与定位
- 产品代号：MindBridge CredVault（简称 CV），版本线 v2.x，面向 AI Agent 与自动化系统的凭证保险库，提供密钥托管、动态下发、自动轮换与最小权限访问。
- 解决的问题：Agent 调用工具/API 时硬编码密钥、凭证散落难审计、权限过大、密钥泄露后难追溯与快速回收。
- 定位为 Agent 与自动化场景的"密钥安全底座"，与 Agent 安全网关联动，实现凭证的集中托管与动态生命周期管理。

## 目标客户
- 大规模运行 AI Agent、RPA 机器人、自动化脚本的企业。
- 管理大量 API Key、数据库口令、云凭证、证书的金融、政务、互联网企业。
- 有强合规审计要求，需对凭证使用全量留痕的机构。

## 核心价值
- 集中托管：统一纳管各类密钥与证书，消除硬编码与散落凭证。
- 动态下发：按需、限时、最小权限下发，用完即弃，避免长期凭证暴露。
- 自动轮换：支持策略驱动自动轮换，降低密钥长期有效带来的风险。

## 适用场景
- Agent 调用第三方 API、数据库、云资源、内部系统凭证的托管与下发；RPA 与 CI/CD 凭证管理。

## 竞品差异
- 对比通用密钥管理（KMS/Vault）：针对 Agent 高频、动态、短时凭证场景做了优化与 SDK；对比硬编码：提供审计、轮换与最小权限自动化。
