# Agent 安全网关 — 产品概述与定位

## 产品代号与定位
- 产品代号：MindBridge AgentGate（简称 AG），版本线 v2.x，面向 AI Agent（智能体）的运行时安全网关，聚焦工具调用白名单与权限最小化。
- 解决的问题：Agent 自主调用工具导致的越权操作、敏感动作失控、提示注入/工具滥用，以及"能力过大"带来的安全与合规风险。
- 定位为 Agent 与外部系统/工具之间的"安全守卫"，统一拦截、审计与管控 Agent 的每一次动作。

## 目标客户
- 已上线或计划上线 AI Agent（客服、运营、办公自动化、内部系统助手）的企业。
- 高度依赖脚本与自动化、工具调用频繁的金融、政企、互联网企业。
- 有强审计与合规要求，需对 Agent 行为全量留痕的机构。

## 核心价值
- 工具调用白名单：仅放行预先授权的工具与参数，未授权一律阻断。
- 权限最小化：最小权限签发临时凭证，动态授予、用完即弃。
- 全链路审计：每次调用留痕，支持回放与告警，满足合规举证。

## 适用场景
- Agent 调用数据库/API/内部系统、访问云资源、执行写操作、触发外部流程等高风险动作的管控。

## 竞品差异
- 对比 RAG/检索增强中间件：我们是独立的运行时安全面，不限 Agent 框架；对比通用 API 网关：增加 Agent 语义理解、意图审计与最小权限动态签发能力。
