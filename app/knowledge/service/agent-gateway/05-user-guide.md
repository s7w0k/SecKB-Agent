# Agent 安全网关 — 使用指南

## 功能操作
- 工具管理：注册工具、定义参数 schema、维护白名单与禁用清单。
- 策略配置：按 Agent/工具/动作（读/写/执行）配置放行、告警、阻断三级策略。
- 权限签发：为 Agent 调用动态签发最小权限凭证，配置有效期与自动回收。
- 观察模式：上线初期以只记录不阻断方式建立调用基线。

## 配置项
- 语义意图审计开关、敏感动作规则（删除、外发、提权）、频率与配额限制、告警阈值。
- 通知：邮件、企业微信/钉钉 Webhook、SIEM。

## 告警与报表
- 告警：未授权工具调用、越权参数、敏感动作、异常频率、提示注入特征。
- 报表：按 Agent/工具的动作分布、拦截统计、风险排行、审计回放。
- 审计：全量调用留痕（调用方、参数、结果、决策），支持合规导出。

## 日常使用
- 定期复核白名单与权限最小化策略；关注语义审计告警；按季度进行权限收敛与基线刷新。
