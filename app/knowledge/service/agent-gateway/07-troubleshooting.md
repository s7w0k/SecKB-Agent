# Agent 安全网关 — 故障排查

## 误拦/漏拦
- 误拦：核对白名单与参数 schema 是否与真实调用匹配，检查语义审计规则是否过严。
- 漏拦：检查是否处于观察模式、策略级别配置错误、SDK 未正确接入。
- 处理：细化 schema、调整规则、确认拦截模式生效；用测试调用验证决策日志。

## 性能下降（延迟升高/吞吐下降）
- 检查策略是否走语义判定过多、数据库/Redis 连接池是否打满、审计写入是否阻塞。
- 检查是否被大量并发调用拖垮。
- 处理：拆分语义判定与本地白名单判定、扩容节点、削峰或异步审计写入。

## 集成失败（SDK 接入/权限签发不通）
- 核对 SDK 版本与网关版本兼容、鉴权与网络白名单；检查与凭证保险库的连接与密钥。
- 检查工具协议（REST/gRPC）映射是否正确。
- 处理：抓取日志按错误码排查，验证最小调用连通后重试。

## 服务异常（网关不可用）
- 检查服务进程与容器健康、数据库与 Redis 状态、证书有效期。
- 处理：重启无状态服务、扩容前排查资源泄漏；持续异常升级 P1 工单。
