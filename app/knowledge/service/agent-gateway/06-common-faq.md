# Agent 安全网关 — 常见问题 FAQ

- 问：能拦截哪些越权行为？
- 答：未授权工具调用、越权参数、敏感操作（删除、外发、提权）、异常频率及提示注入特征均可拦截。
- 问：会不会影响 Agent 性能？
- 答：本地策略判定附加延迟 ≤ 5ms，语义级判定 ≤ 50ms，对整体体验影响极小。
- 问：支持哪些 Agent 框架？
- 答：原生适配 LangChain、LlamaIndex、AutoGen 及自研 Agent，支持 REST/gRPC 工具协议。
- 问：如何减小误拦？
- 答：建议先以观察模式收集基线，调优白名单后再切换拦截模式，可逐步放量。
- 问：最小权限是怎么实现的？
- 答：联动凭证保险库，为每次调用动态签发最小权限、限时凭证，用完即回收。
- 问：是否支持私有化？
- 答：支持，可部署于客户机房或专有云，也支持 Sidecar 嵌入 Agent 服务。
- 问：审计日志能保存多久？
- 答：默认 180 天，可配置延长或对接 SIEM 归档合规模时间要求。
- 问：新增工具需要重新配置吗？
- 答：需注册并加入白名单，否则默认拒绝，确保新增工具经过安全评估。
- 问：能识别提示注入吗？
- 答：内置语义意图审计可识别典型提示注入与越权指令，可配置命中动作。
- 问：与现有 API 网关冲突吗？
- 答：不冲突，AgentGate 专注 Agent 语义层安全，可叠加在 API 网关之上。
