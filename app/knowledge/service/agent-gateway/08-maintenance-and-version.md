# Agent 安全网关 — 维保升级与版本发布

## 升级流程
- 升级前备份策略与审计数据、核对兼容性矩阵；先在测试环境验证再灰度升级。
- 节奏：每季度功能版本，每月安全补丁，按需紧急修复；支持滚动升级与回滚。
- 升级操作：先升级策略引擎，再升级 SDK/接入层，执行迁移脚本与回归拦截测试。

## 版本历史
- v2.0（2025-05）：工具白名单与三级策略、全量审计。
- v2.1（2025-09）：语义意图审计、观察模式、保险库最小权限联动。
- v2.2（2026-01）：提示注入识别增强、频率配额、SIEM 审计管道。
- 当前推荐 LTS：v2.2（LTS），维护支持至 2028-01。

## 兼容性与升级影响
- 升级前核对 Agent SDK 与网关版本兼容（需同大版本）；API 保持向后兼容。
- 策略与历史审计数据不受升级影响，升级后需复核白名单配置。

## 退役与下线策略
- LTS 停更后提供 12 个月安全维护期，之后进入退役观察期。
- 下线前导出并迁移策略与审计日志，完成权限与凭证回收确认。
- EOL 前 90 天邮件通知，协助规划升级路径。
