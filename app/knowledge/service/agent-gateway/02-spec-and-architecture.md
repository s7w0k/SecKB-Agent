# Agent 安全网关 — 规格参数与系统架构

## 性能指标
- 网关吞吐：单节点 ≥ 5000 次工具调用/分钟，P99 附加延迟 ≤ 5ms（策略本地判定）。
- 支持纳管 Agent/工具规模：单实例 ≥ 1000 个 Agent、≥ 5000 个工具注册。
- 语义级策略判定（含意图审计）延迟 ≤ 50ms；异步审计日志写入 ≥ 2000 条/秒。

## 组件架构
- 接入层：Agent SDK/API 网关入口，支持主流框架（LangChain、LlamaIndex、自研 Agent）。
- 策略引擎：工具白名单、参数校验、上下文感知意图审计、风险动作识别。
- 权限服务：连接凭证保险库/DKMS 做最小权限签发与动态授权。
- 审计与告警：全量调用留痕、实时告警、行为回放与报表。

## 部署形态与依赖
- 支持私有化（VM/K8s）与 Sidecar 模式嵌入 Agent 服务；支持与 Agent 凭证保险库联动。
- 依赖：PostgreSQL、Redis、可选 Kafka 审计管道；可对接企业 SSO/LDAP。
- 软硬件规格：最小 8 核/32GB；典型生产 16 核/64GB，支持横向扩展保证高吞吐。

## 兼容性
- 支持 LangChain、LlamaIndex、AutoGen 等主流 Agent 框架及自研 Agent；支持 REST/gRPC 工具协议。
