# Agent 安全网关 — 商务与交付方案

## 报价模型
- 订阅制：按纳管 Agent 实例数计费，基础版每 Agent 500 元/年起，含标准策略与审计。
- 私有化授权：一次性授权费 + 年维保费（15%），按并发调用量或 Agent 规模计费。
- 企业版含语义意图审计、保险库联动、高可用与定制策略模板；提供 30 天试用与 14 天 POC。

## 交付流程
- 阶段一（盘点与策略）：1—2 周梳理 Agent 与工具清单，建立白名单与权限基线。
- 阶段二（POC）：2 周内完成网关接入、策略生效与审计验证，输出 POC 报告。
- 阶段三（正式交付）：1—2 周完成生产部署、保险库联调、培训与验收。
- 总交付：标准 4—5 周，复杂多 Agent/多系统 ≤ 6 周。

## SLA 与合同要点
- 服务可用性 ≥ 99.9%；P1 故障 15 分钟响应、4 小时止损。
- 合规要点：策略默认拒绝、全量审计留痕；支持符合等保与数据安全法规的条款；明确 Agent 越权行为追溯责任约定。

## POC 验收指标
- 白名单拦截率与误拦率、附加延迟、审计完整性、与保险库的权限下发正确性。
