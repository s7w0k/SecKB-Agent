# Agent 安全网关 — 部署安装与集成

## 环境要求
- 硬件：x86_64 服务器，≥ 8 核 CPU、≥ 32GB 内存、SSD ≥ 500GB（审计日志存储建议更大）。
- 系统：Ubuntu 20.04/22.04、CentOS 7.9；Docker ≥ 20.10、Kubernetes ≥ 1.24。
- 网络：需与 Agent 服务、目标工具系统、凭证保险库互通；审计管道可对接 Kafka。

## 安装步骤
- 部署网关服务 -> 配置数据库与 Redis -> 建立白名单与初始策略 -> 接入 Agent SDK 或流量代理 -> 验证拦截 -> 创建管理员。
- 提供一键脚本与 Helm 部署，支持 Sidecar 与独立网关两种接入形态。

## API/SDK 集成
- 提供 Agent SDK（Python/Java/Go）与 RESTful API；支持拦截配置、策略管理、审计查询与告警回调。
- 原生适配 LangChain/LlamaIndex 工具调用，可无侵入或轻改造接入自研 Agent。

## 与客户系统对接
- 对接企业 SSO/LDAP 统一认证；对接 Agent 凭证保险库做最小权限签发；对接 SIEM 汇聚审计日志。
- 支持将工具清单与白名单同步到客户 CMDB。

## 注意事项
- 上线前建议先以"观察模式"运行，收集真实调用基线后再切换为拦截模式，降低误拦影响。
