# Agent 身份与访问管理 — 常见问题 FAQ

- 问：与通用 IAM/SSO 有何区别？
  答：通用 IAM 面向人，本产品面向 Agent 会话级身份，支持工具级细粒度授权、短时令牌与最小权限自动收敛，可与既有 IAM 互补集成。

- 问：如何保证令牌安全？
  答：支持短时令牌（默认 5 分钟至 1 小时）、mTLS 双向认证、KMS/HSM 托管密钥，降低凭据泄露影响面。

- 问：多个 Agent 需要用独立身份吗？
  答：建议每个 Agent 独立身份令牌，实现"人—Agent—任务"完整映射，便于审计追溯与最小权限。

- 问：支持哪些身份源？
  答：支持 AD、LDAP、企业 SSO、云 IAM，支持 OIDC/OAuth2.0/mTLS 标准协议。

- 问：最小权限如何落地？
  答：提供权限使用分析，自动识别冗余授权并生成收敛建议，支持一键收敛与审批。

- 问：权限变更多久生效？
  答：策略变更默认 ≤30s 生效，支持实时同步到授权服务。

- 问：支持哪些 Agent 框架？
  答：支持 LangChain、AutoGen、CrewAI 等，可自动注入身份令牌并在工具调用时校验授权。

- 问：令牌被泄露风险如何处理？
  答：支持快速吊销、自动失效与异常使用告警，可通过审计还原泄露路径。

- 问：是否支持信创与本地化部署？
  答：支持私有化与鲲鹏、飞腾等信创架构，密钥可本地托管。

- 问：与隔离沙箱、审计产品如何联动？
  答：身份驱动授权，沙箱按身份执行隔离，审计按身份留痕，形成完整安全闭环。
