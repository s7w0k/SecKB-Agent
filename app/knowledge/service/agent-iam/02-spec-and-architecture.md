# Agent 身份与访问管理 — 规格参数与系统架构

## 核心性能指标
- 令牌签发吞吐 ≥ 50000 次/秒，令牌校验 P99 ≤ 5ms
- 支持并发在线 Agent 会话 ≥ 100 万，策略评估延迟 ≤ 10ms
- RBAC 策略规模支持 ≥ 10 万条，权限变更生效 ≤ 30s
- 支持短时令牌（默认 5 分钟至 1 小时）与刷新令牌机制

## 部署形态
- 私有化：支持 x86_64 / ARM64 / 信创架构，高可用双活或三节点模式
- 容器化：兼容 Kubernetes，提供 Helm 一键部署
- 支持与客户 AD/LDAP/SSO 对接，作为统一身份源

## 组件架构
- 身份服务：身份注册、令牌签发与校验、证书管理（PKI）
- 授权服务：RBAC 策略引擎、权限评估、最小权限收敛
- 关联组件：审计通道、密钥管理（KMS）、SDK 客户端

## 依赖与规格
- 依赖 KMS 或硬件加密机（HSM）用于密钥管理；生产建议 3 节点 8 核 16GB
- 支持 OIDC / OAuth2.0 / mTLS 标准协议，兼容主流身份源
- 对外接口：RESTful API + Python / Go SDK，支持 JWT / SPIFFE 格式令牌
