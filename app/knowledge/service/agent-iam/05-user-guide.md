# Agent 身份与访问管理 — 使用指南

## 核心功能操作
- 身份管理：注册/吊销 Agent 身份，维护"人—Agent—任务"映射关系
- 令牌管理：签发、刷新、吊销短时令牌，查看令牌使用记录
- 权限管理：配置 RBAC 角色与策略，为 Agent 分配工具级/资源级权限
- 最小权限收敛：自动分析权限使用情况，收敛冗余授权

## 配置项说明
- 令牌策略：有效期（默认 5 分钟至 1 小时）、刷新窗口、续签规则
- 认证方式：OIDC/OAuth2.0/mTLS，可配置多因素校验
- 授权粒度：资源级、工具级、字段级细粒度策略
- 身份源同步：AD/LDAP/SSO 同步频率与过滤规则

## 告警与报表
- 告警：异常令牌使用、越权访问、权限变更、爆破尝试均触发告警
- 报表：权限矩阵、最小权限符合度、令牌使用趋势、身份访问审计报表
- 支持导出与定时生成，满足合规审阅与监管报送

## 日常使用建议
- 建议定期（每月）执行权限审阅与最小权限收敛
- 对高权限 Agent 启用短时令牌与告警，缩短暴露窗口
- 将身份访问日志接入审计观测平台统一留痕
