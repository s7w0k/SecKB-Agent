# Agent 身份与访问管理 — 维保升级与版本发布

## 升级流程
- 升级前：备份身份库、策略与密钥配置，核对版本兼容矩阵，申请变更窗口
- 升级中：在低峰期执行，先升级授权服务，再升级身份服务与 SDK 网关
- 升级后：执行令牌签发/校验回归，核对策略与密钥状态，检查身份源同步
- 建议升级频率：季度安全补丁、年度大版本演进

## 补丁管理
- 安全补丁（令牌漏洞、密码学缺陷）随版本发布，高危缺陷 24 小时内出补丁
- 补丁发布前完成内部回归，提供一键回滚与升级说明

## 版本历史
- v1.0：首个商用版本，支持 Agent 身份与 RBAC 授权
- v1.2：新增 mTLS 与短时令牌机制，支持信创架构
- v1.5：引入最小权限自动收敛与权限使用分析
- v2.0：令牌签发吞吐提升至 5 万次/秒，支持大规模并发会话

## 兼容性
- SDK 向后兼容一个主版本；令牌格式兼容 OIDC/JWT/SPIFFE
- 升级前确认与隔离沙箱、审计产品及身份源的版本匹配

## 退役/下线策略
- 退役前提供身份与策略导出、令牌回收工具，确保无残留授权
- 下线流程包括：确认替代方案、吊销全部令牌、导出身份数据、执行下线评审
- 提供 6 个月过渡期支持，期满后关闭身份服务并归档审计数据
