# Agent 身份与访问管理 — 故障排查

## 现象一：令牌签发/校验变慢
- 排查步骤：检查授权服务节点负载与网络延迟；核对 KMS 性能与密钥缓存
- 检查令牌并发与策略规模是否超规格；查看令牌缓存命中率
- 定位点为"资源优先"：扩容授权节点或优化 KMS 缓存

## 现象二：越权/误授权（最小权限失真）
- 排查步骤：检查 RBAC 策略是否被误配置；核对权限变更记录与审批流程
- 检查身份源同步是否引入多余角色；查看权限收敛建议命中情况
- 定位点为"策略优先"：复核策略配置与权限变更审计

## 现象三：集成失败（SDK/身份源）
- 排查步骤：核对 SDK 版本兼容性；检查 AD/LDAP/SSO 连通性与协议配置
- 检查令牌格式与签名证书是否匹配；查看身份同步日志与错误码
- 定位点为"接口优先"：抓取请求/响应报文比对文档

## 现象四：服务异常/令牌大规模失效
- 排查步骤：检查授权服务进程与密钥轮换状态；核对 KMS 可用性
- 检查时钟同步（NTP）是否漂移导致令牌校验失败；查看证书有效期
- 定位点为"状态优先"：核对服务状态、密钥与时钟

## 通用建议
- 收集身份服务日志目录 `/var/log/iam/`，保留现场后联系售后
- 提供产品版本号、令牌 ID、错误码与复现步骤便于快速定位
