# Agent 身份与访问管理 — 产品概述与定位

## 解决的核心问题
- 企业 Agent 以高权限身份运行、身份与会话混淆，越权访问与凭据泄露风险高
- 解决"Agent 身份不可区分、权限不可治理、最小权限难落地"三类核心痛点

## 目标客户
- 需要精细权限管控的金融、能源、政务行业，以及强监管行业
- 已有身份治理体系（IAM/SSO）但需扩展到 Agent 场景的大型企业

## 核心价值
- 为每个 Agent 颁发独立身份令牌，实现"人—Agent—任务"的完整身份映射
- 提供基于 RBAC 的细粒度权限模型，支持最小权限自动收敛与动态授权
- 支持 mTLS 双向认证与短时令牌，降低凭据泄露影响面
- 与隔离沙箱、审计产品联动，形成身份驱动的安全闭环

## 适用场景
- Agent 调用企业 API/数据库/云资源的权限控制
- 多 Agent 共享账密时的身份隔离与最小化授权
- 外包/第三方 Agent 接入时的身份治理与审计追溯

## 竞品差异
- 相比通用 IAM，原生支持 Agent 会话级身份与工具级细粒度授权
- 相比开源 Keycloak 等，提供 Agent 令牌生命周期管理与最小权限自动收敛
- 支持与客户既有 AD/LDAP/SSO 平滑集成
