# Agent 身份与访问管理 — 商务与交付方案

## 报价模型
- 按 Agent 身份数与并发会话规模订阅：标准版（≤1 万身份）、企业版（≤10 万）、旗舰版（不限）
- 支持按年订阅；提供令牌容量、策略数、KMS 集成的增值包
- 提供信创环境与专属定制化服务报价

## 交付流程
- 阶段一：身份与权限现状调研（1-2 周），输出身份治理方案
- 阶段二：POC 验证（1-2 周），完成与客户身份源及 Agent 框架的对接演示
- 阶段三：正式部署与身份源集成（2-4 周），配置 RBAC 与策略
- 阶段四：试运行与验收（2 周），输出权限收敛报告与验收文档

## SLA 承诺
- 服务可用性 ≥ 99.95%，令牌签发与校验链路 7×24 监控
- 故障响应 15 分钟内，重大故障 1 小时内恢复
- 提供季度权限审阅与最小权限符合度评估报告

## 合同与合规要点
- 满足等保 2.0、ISO 27001 的访问控制与身份管理要求
- 支持数据本地化、密钥托管与责任边界条款约定
- 满足个保法对最小权限原则与访问留痕的要求
