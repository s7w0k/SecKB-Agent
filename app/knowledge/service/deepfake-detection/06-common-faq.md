# 深度伪造鉴别平台 — 常见问题 FAQ

- 问：平台能识别哪些类型的伪造？
- 答：支持 AI 换脸、图像生成（GAN/Diffusion）、视频逐帧篡改、语音克隆四大类，多模态融合打分，输出概率与篡改热力图。
- 问：检测成功率高吗？
- 答：公开基准 AUC ≥ 0.985，业务场景综合准确率 ≥ 96%，误报率 ≤ 0.5% 可按阈值调节。
- 问：检测结果能否作为司法证据？
- 答：可配置证据留存模式，全量审计留痕并输出特征指纹，满足司法鉴定辅助要求，但仍需人工复核。
- 问：是否支持私有化部署？
- 答：支持，可部署于客户机房或专有云，离线/隔离网络环境可用。
- 问：视频检测延迟多久？
- 答：在线 API 视频 P99 ≤ 800ms（≤30s 短片），更长视频走异步批量，时长与分辨率上限见接口文档。
- 问：误报太高怎么办？
- 答：可调高阈值或关闭对应检测器，并结合样本回测与服务日历优化；建议先做业务样本基线。
- 问：数据是否会被留存？
- 答：留存策略可配置，默认 180 天，可开启"不落盘"模式仅保留检测结论。
- 问：支持哪些格式？
- 答：图像 JPEG/PNG/RAW，视频 MP4/H.264/H.265/AVI，音频 WAV/MP3。
- 问：如何与现有系统对接？
- 答：提供 RESTful API、Java/Python/Go SDK、Webhook 回调，可对接 KYC、CMS、视频会议等系统。
- 问：采购后的升级与维保？
- 答：年维保含模型更新、补丁与技术支持；模型版本支持灰度升级，不在维保期内需单独购买。
