# 深度伪造鉴别平台 — 部署安装与集成

## 环境要求
- 硬件：x86_64 服务器，≥ 16 核 CPU、≥ 64GB 内存、NVIDIA GPU（显存 ≥ 16GB）；磁盘 SSD ≥ 1TB。
- 系统：Ubuntu 20.04/22.04、CentOS 7.9 或兼容发行版；Docker ≥ 20.10、Kubernetes ≥ 1.24。
- 网络：需与检测命名空间、对象存储、认证（LDAP/OIDC）互通；默认开放 8443（HTTPS）、9092（Kafka）。

## 安装步骤
- 导入离线镜像包 -> 配置 env 文件（数据库、存储、密钥）-> 初始化数据库 -> 启动服务 -> 健康检查（/health 返回 OK）-> 创建管理员账号。
- 提供一键安装脚本与 Helm Chart 两种方式；支持不停机滚动升级。

## API/SDK 集成
- 提供 RESTful API（图像/视频/音频检测、结果回调）、Webhook 通知、Java/Python/Go SDK。
- 典型调用：上传或引用 URI -> 返回 jobId -> 异步轮询或回调拿检测结果（含概率、热力图、指纹）。
- 与客户系统对接：支持对接人脸识别/KYC 平台、内容管理 CMS、视频会议系统；支持 Kafka/MinIO 批量接入存量资产。

## 对接注意事项
- 约定数据脱敏等级与握手鉴权（OAuth2/mTLS）；视频时长与分辨率上限请在接口文档确认。
