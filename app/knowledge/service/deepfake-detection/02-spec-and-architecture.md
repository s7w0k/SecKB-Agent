# 深度伪造鉴别平台 — 规格参数与系统架构

## 性能指标
- 在线 API 单路 P99 延迟 ≤ 300ms（图像）、≤ 800ms（≤30s 视频）、≤ 500ms（≤60s 音频）。
- 单节点吞吐 ≥ 200 QPS（图像），视频检测按并发路数计，单集群支持 ≥ 500 路并发；支持横向扩容，吞吐线性扩展。
- 检测准确率：公开基准（Deepfake Detection Challenge / FaceForensics++）AUC ≥ 0.985；真实业务场景综合准确率 ≥ 96%，误报率 ≤ 0.5% 可调。

## 组件架构
- 采集接入层：RESTful API、消息队列（Kafka）批量接入、对象存储（S3/MinIO/OSS）扫描。
- 检测引擎：图像检测器、视频时空检测器、音频克隆检测器、多模态融合打分模块。
- 决策与证据层：伪造概率、篡改热力图、特征指纹、审计留存。
- 管理平台：策略配置、告警中心、报表、模型版本管理、权限管控。

## 部署形态与依赖
- 支持私有化虚拟机/物理机/Kubernetes 部署，也提供与云（阿里云/腾讯云/华为云）兼容的镜像包。
- 推理依赖：NVIDIA GPU（Tesla T4/A10/A100 及以上），CUDA ≥ 11.8；软件依赖 Python 3.10、PyTorch ≥ 2.0、Redis、PostgreSQL。
- 软硬件规格：最小生产环境 4 张 T4 起；典型 8 卡 A10 集群支持日处理 200 万条图像或 2 万小时视频。

## 兼容性
- 支持主流音视频封装（MP4/H.264/H.265/AVI/WAV/MP3）与人脸库格式（JPEG/PNG/RAW）。
