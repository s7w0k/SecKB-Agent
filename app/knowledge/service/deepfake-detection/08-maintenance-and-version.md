# 深度伪造鉴别平台 — 维保升级与版本发布

## 升级流程
- 升级前备份数据库与配置、核对版本兼容性；建议零售环境中验证。
- 版本节奏：每季度功能版本，每月安全补丁，按需紧急热修复；采用灰度发布与回滚预案。
- 升级操作：先升级检测引擎镜像，再升级管理平台，最后跑迁移脚本与回归测试；全程可回退至上版本。

## 版本历史
- v3.0（2025-06）：多模态融合引擎、篡改热力图、证据留存模式。
- v3.1（2025-09）：语音克隆检测增强、Kafka 批量接入、模型灰度发布。
- v3.2（2026-01）：Diffusion 生成检测、误报率自适应阈值、报表增强。
- 当前推荐 LTS：v3.2（LTS），维护支持至 2028-01。

## 兼容性与升级影响
- 升级前确认操作系统、GPU 驱动、CUDA、数据库版本兼容矩阵；评估 API 兼容性（v3.x 保持向后兼容，字段只增不改）。
- 模型更新不影响已生成的历史检测结论，仅影响后续检测。

## 退役与下线策略
- LTS 版本自停更后提供 12 个月安全维护期，之后进入退役观察期。
- 下线前需导出并迁移审计日志与证据数据，完成数据归属确认；提供迁移工具与数据导出模板，确保客户取证数据不丢失。
- 版本 EOL 前 90 天邮件通知客户，协助规划升级路径。
