# AI 内容安全审核引擎 — 规格参数与系统架构

## 性能指标
- 文本审核单请求 ≤ 50ms，图片审核 ≤ 200ms，音频 ≤ 300ms，视频抽帧审核 ≤ 500ms/帧
- 单节点吞吐 ≥ 2,000 次/秒（文本），支持水平扩展至 ≥ 50,000 次/秒
- 违规召回率 ≥ 99%，误报率 ≤ 2%，人工复核率可调
- 审核可用性 ≥ 99.9%，支持多地容灾

## 部署形态
- 支持 SaaS API、私有化容器部署、一体机交付与混合部署
- 私有化支持 GPU 推理（模型版）与纯 CPU 轻量版

## 组件架构
- 接入层（Gateway）：统一审核 API、鉴权、限流、异步回调
- 审核引擎（Engine）：文本语义模型、图像/音视频模型、敏感词+规则双引擎
- 策略服务（Policy）：类目策略、阈值、处置动作（放行/拦截/人工）、白名单
- 证据与存储服务（Evidence）：命中证据、审核流水、图片/片段留存
- 控制台（Console）：策略配置、实时报表、人工复核工单、效果调优

## 依赖与软硬件规格
- 文本版最小 8 vCPU / 16GB；多模态版需 1 张 GPU（如 A10 以上）起
- 依赖 PostgreSQL 15+ 或国产数据库、Redis 7+、对象存储（证据留存）
- 支持国产化系统（麒麟/统信）与国产 GPU（昇腾/寒武纪）适配
- 支持对接多家云审核能力作为本地引擎的补充或兜底
