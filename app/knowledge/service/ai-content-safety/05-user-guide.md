# AI 内容安全审核引擎 — 使用指南

## 功能操作
- 内容送审：通过 API 提交文本/图片/音频/视频，实时获取审核结论与处置建议
- 策略配置：启用/停用类目（涉政、色情、暴力、广告、辱骂、违禁等），设置阈值
- 处置动作：为不同类目配置放行/拦截/转人工/加白，支持按用户等级差异化
- 人工复核：在控制台处理转人工内容，复核结果可回流训练

## 配置项
- 类目阈值：风险分数阈值，可精确到每类目与每终端
- 自定义词库：企业专属敏感词、行业术语、品牌词管理
- 白名单：会员/已认证用户/特定内容命中策略可自动放行
- 留存策略：证据图片与录音留存周期（默认 90 天），满足合规要求

## 告警与报表
- 实时监控：审核 QPS、命中率、类目分布、处置占比
- 告警规则：命中率突增、接口超时、引擎异常自动告警
- 合规报表：按类目/时间/处置动作生成审核统计与违规趋势报告
- 支持导出审核流水与证据包，供监管举证与内审使用

## 日常使用
- 每日查看命中与人工复核工单，及时处理高风险内容
- 每周复盘误报案例，优化词库与阈值
- 新内容形态上线前，用历史样本回归验证策略效果
- 定期同步厂商类目模型与词库更新，关注新规合规要求
