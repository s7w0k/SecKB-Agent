# AI 内容安全审核引擎 — 部署安装与集成

## 环境要求
- 操作系统：CentOS 7.9+、Ubuntu 20.04+、麒麟 V10、统信 UOS
- 文本版最小 8 vCPU / 16GB / 100GB；多模态版需 GPU（NVIDIA A10+ 或国产 GPU）
- 容器化：Kubernetes 1.24+ / Docker 20.10+；离线安装包 .tar.gz
- 网络：引擎需与数据库、Redis、对象存储互通，开放审核 API 端口

## 安装步骤
- 使用 Helm Chart 或离线包部署核心服务，初始化数据库与对象存储
- 加载类目模型与词库，创建审核策略模板
- 配置鉴权密钥与限流，接入监控探针，执行连通性与效果自检

## API/SDK 集成
- 提供统一同步审核 API 与异步批量审核接口（任务回调）
- 提供 Java / Go / Python / Node.js 官方 SDK，文本/图片/音频/视频统一接口
- 支持 Webhook 回传审核结果与人工复核事件

## 与客户系统对接
- 对接 UGC 发布链路、消息/评论系统，实现发布前实时审核
- 对接直播/音视频平台，实现分钟级整场自动审核
- 支持人工复核结果回流训练，持续优化类目模型
- 支持对接 SIEM/审计平台归档审核流水，满足合规举证
