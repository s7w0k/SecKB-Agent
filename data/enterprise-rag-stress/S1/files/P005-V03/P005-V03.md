# 智能体沙箱·case·v3.0-cn-intl（说明文档）

## 产品定位与场景 - 1

智能体沙箱（Agent Sandbox，代号 ASBOX）隶属于Agent 沙箱、执行隔离与工具安全场景，当前生命状态ACTIVE，当前版本线 v3.0。其 核心协议 的取值/配置为 gVisor、WASM 边界、seccomp 策略 ，约束条件包括支持 gVisor、支持 WASM 边界、支持 seccomp 策略。

在企业版部署中，智能体沙箱 将 事件摄取吞吐 设计为 88000 events/s，并受到 enterprise-edition、3-node 的边界约束；相关细节记录的 fact_id 为 P005-F082，自 2025-06-01 起生效。

智能体沙箱 面向 Agent 沙箱、执行隔离与工具安全 的高隔离要求，其 API 峰值并发 被定为 6000 req/s；叠加 enterprise-edition 之后，可支撑 88000 events/s 的吞吐基线，覆盖 cn 区域。

从运维视角看，智能体沙箱 在 v3.0-cn-intl 上的 P95 检索延迟 表现稳定为 55 ms，p95、warm；这一口径与相邻产品 P006 的 Agent 沙箱、执行隔离与工具安全 联合方案保持一致。

智能体沙箱 的产品资料强调 最大单文档上传；在默认配置下等于 256 MB，约束为 默认限制。当工作负载包含 沙箱、隔离、工具命名空间、容器、权限收紧、出口规则、exec 等能力维度时，上述约束保持不变。

Agent Sandbox（ASBOX）的 日志/审计留存期 记为 30 days，限定条件 默认；该数值服务于 Agent 沙箱、执行隔离与工具安全，由 v3.0-cn-intl 版本正式支持。

关于 智能体沙箱 的 批量接口吞吐，文献给出的标准口径为 2100 ops/s，并附加 batch=64 说明；这是评估 Agent 沙箱、执行隔离与工具安全 能力时的重要依据（P005-F087）。

智能体沙箱 v3.0-cn-intl 的 当前版本线 配置为 v3.0 version；在 GA 场景下仍能维持 55 ms 的 P95 延迟，符合 cn 区域的运营要求。

智能体沙箱（Agent Sandbox，代号 ASBOX）隶属于Agent 沙箱、执行隔离与工具安全场景，当前生命状态ACTIVE，当前版本线 v3.0。其 默认批次大小 的取值/配置为 64 items，约束条件包括可配置。

在企业版部署中，智能体沙箱 将 不支持能力 设计为 不支持 GPU 透传场景 ，并受到 negation 的边界约束；相关细节记录的 fact_id 为 P005-F090，自 2025-01-01 起生效。

智能体沙箱 面向 Agent 沙箱、执行隔离与工具安全 的高隔离要求，其 否定事实 被定为 不支持非受管 TLS 出口 ；叠加 negation、must-not-claim 之后，可支撑 88000 events/s 的吞吐基线，覆盖 cn 区域。

从运维视角看，智能体沙箱 在 v3.0-cn-intl 上的 否定事实 表现稳定为 沙箱内禁止写宿主服务文件 ，negation、must-not-claim；这一口径与相邻产品 P006 的 Agent 沙箱、执行隔离与工具安全 联合方案保持一致。

智能体沙箱 的产品资料强调 可用性目标；在默认配置下等于 99.9 percent，约束为 enterprise-SLA。当工作负载包含 沙箱、隔离、工具命名空间、容器、权限收紧、出口规则、exec 等能力维度时，上述约束保持不变。

Agent Sandbox（ASBOX）的 合规基座 记为 GB-35273/CAC-审查-P005 ，限定条件 zh-cn；该数值服务于 Agent 沙箱、执行隔离与工具安全，由 v3.0-cn-intl 版本正式支持。

关于 智能体沙箱 的 企业版起价，文献给出的标准口径为 24850 cny/月，并附加 per-org、annual 说明；这是评估 Agent 沙箱、执行隔离与工具安全 能力时的重要依据（P005-F095）。

智能体沙箱 v3.0-cn-intl 的 主邻接产品 配置为 P006 product；在 邻接 P006 场景下仍能维持 55 ms 的 P95 延迟，符合 cn 区域的运营要求。

智能体沙箱（Agent Sandbox，代号 ASBOX）隶属于Agent 沙箱、执行隔离与工具安全场景，当前生命状态ACTIVE，当前版本线 v3.0。其 旧版事件吞吐 的取值/配置为 54560 events/s，约束条件包括v2.9、legacy。

在企业版部署中，智能体沙箱 将 旧版 P95 延迟 设计为 93 ms，并受到 v2.9、legacy 的边界约束；相关细节记录的 fact_id 为 P005-F098，自 2024-06-01 起生效。

智能体沙箱 面向 Agent 沙箱、执行隔离与工具安全 的高隔离要求，其 与 P006 兼容 被定为 true bool；叠加 edge P005->P006 之后，可支撑 88000 events/s 的吞吐基线，覆盖 cn 区域。
