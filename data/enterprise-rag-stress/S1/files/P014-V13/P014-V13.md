# LLM 安全网关·relations·v5.0-cn-intl（说明文档）

## 产品定位与场景 - 1

LLM 安全网关（LLM Security Gateway，代号 LSGW）隶属于审计、可观测性和安全运营场景，当前生命状态ACTIVE，当前版本线 v5.0。其 核心协议 的取值/配置为 提示注入拦截、PII 检测、策略旁路 ，约束条件包括支持 提示注入拦截、支持 PII 检测、支持 策略旁路。

在企业版部署中，LLM 安全网关 将 事件摄取吞吐 设计为 760000 events/s，并受到 enterprise-edition、3-node 的边界约束；相关细节记录的 fact_id 为 P014-F262，自 2025-06-01 起生效。

LLM 安全网关 面向 审计、可观测性和安全运营 的高隔离要求，其 API 峰值并发 被定为 15000 req/s；叠加 enterprise-edition 之后，可支撑 760000 events/s 的吞吐基线，覆盖 cn 区域。

从运维视角看，LLM 安全网关 在 v5.0-cn-intl 上的 P95 检索延迟 表现稳定为 35 ms，p95、warm；这一口径与相邻产品 P001 的 审计、可观测性和安全运营 联合方案保持一致。

LLM 安全网关 的产品资料强调 最大单文档上传；在默认配置下等于 32 MB，约束为 默认限制。当工作负载包含 注入、安全网关、拦截、PII、策略、输出检测、旁路、红队 等能力维度时，上述约束保持不变。

LLM Security Gateway（LSGW）的 日志/审计留存期 记为 90 days，限定条件 默认；该数值服务于 审计、可观测性和安全运营，由 v5.0-cn-intl 版本正式支持。

关于 LLM 安全网关 的 批量接口吞吐，文献给出的标准口径为 9800 ops/s，并附加 batch=256 说明；这是评估 审计、可观测性和安全运营 能力时的重要依据（P014-F267）。

LLM 安全网关 v5.0-cn-intl 的 当前版本线 配置为 v5.0 version；在 GA 场景下仍能维持 35 ms 的 P95 延迟，符合 cn 区域的运营要求。

LLM 安全网关（LLM Security Gateway，代号 LSGW）隶属于审计、可观测性和安全运营场景，当前生命状态ACTIVE，当前版本线 v5.0。其 默认批次大小 的取值/配置为 256 items，约束条件包括可配置。
