# 多智能体安全·overview·v1.4-cn（说明文档）

## 产品定位与场景 - 1

多智能体安全（Multi-Agent Security，代号 MASEC）隶属于Agent 沙箱、执行隔离与工具安全场景，当前生命状态ACTIVE，当前版本线 v1.4。其 核心协议 的取值/配置为 子代理委派、消息签名 ，约束条件包括支持 子代理委派、支持 消息签名。

在企业版部署中，多智能体安全 将 事件摄取吞吐 设计为 40000 events/s，并受到 standard-edition、3-node 的边界约束；相关细节记录的 fact_id 为 P006-F102，自 2025-06-01 起生效。

多智能体安全 面向 Agent 沙箱、执行隔离与工具安全 的高隔离要求，其 API 峰值并发 被定为 2500 req/s；叠加 standard-edition 之后，可支撑 40000 events/s 的吞吐基线，覆盖 cn 区域。

从运维视角看，多智能体安全 在 v1.4-cn 上的 P95 检索延迟 表现稳定为 18 ms，p95、warm；这一口径与相邻产品 P005 的 Agent 沙箱、执行隔离与工具安全 联合方案保持一致。

多智能体安全 的产品资料强调 最大单文档上传；在默认配置下等于 20 MB，约束为 默认限制。当工作负载包含 委派、子代理、权限边界、消息令牌、编排、身份传播、命名空间 等能力维度时，上述约束保持不变。

Multi-Agent Security（MASEC）的 日志/审计留存期 记为 180 days，限定条件 默认；该数值服务于 Agent 沙箱、执行隔离与工具安全，由 v1.4-cn 版本正式支持。

关于 多智能体安全 的 批量接口吞吐，文献给出的标准口径为 1900 ops/s，并附加 batch=96 说明；这是评估 Agent 沙箱、执行隔离与工具安全 能力时的重要依据（P006-F107）。

多智能体安全 v1.4-cn 的 当前版本线 配置为 v1.4 version；在 GA 场景下仍能维持 18 ms 的 P95 延迟，符合 cn 区域的运营要求。
